## 学習目標

このレベルを修了すると、以下ができるようになります：

- LLMOpsにおけるLangfuseの役割を説明できる
- Langfuseの環境をセットアップし、APIキーを取得できる
- 最初のトレースを送信し、UIで確認できる
- Trace / Observation / Session / Score の関係を説明できる
