# Langfuse トレーニングコンテンツ

LLMアプリケーション開発者のための、Langfuse 完全習得プログラムです。
初心者からプロフェッショナルまで、5段階のレベルで体系的に学習できます。

## カリキュラム構成

| レベル | 対象者 | 内容 |
|--------|--------|------|
| [Level 1: 基礎](./level-1/1-0-README.md) | LLMアプリ開発初学者 | 概念理解・セットアップ・UI操作 |
| [Level 2: 実践入門](./level-2/2-0-README.md) | SDK利用開始者 | トレーシング・SDK統合・フレームワーク連携 |
| [Level 3: 中級](./level-3/3-0-README.md) | 開発チーム | プロンプト管理・評価・データセット |
| [Level 4: 上級](./level-4/4-0-README.md) | テックリード/MLOps | 本番運用・自動化・チーム連携 |
| [Level 5: プロフェッショナル](./level-5/5-0-README.md) | プラットフォームエンジニア | セルフホスト・アーキテクチャ・カスタマイズ |

## 前提知識

- Python または JavaScript/TypeScript の基本的なプログラミング経験
- LLM API（OpenAI等）の基本的な利用経験（Level 2以降）
- コンテナ技術の基礎知識（Level 5）

## 環境要件

### オプションA: Langfuse Cloud（Level 1〜3 推奨）

- ブラウザのみで開始可能
- 無料枠で十分にハンズオン可能

### オプションB: ローカル Podman Compose（Level 4〜5 推奨）

- Podman 4.x 以上 + podman-compose 1.0.6+
- RAM 8GB以上（推奨16GB）
- ディスク空き 5GB以上

## 学習の進め方

1. 各レベルのモジュールを順番に進めてください
2. 各モジュール末尾の「確認問題」で理解度をチェック
3. `code-examples/` ディレクトリのサンプルコードを実際に動かしましょう
4. 必要に応じて前のレベルに戻って復習してください
