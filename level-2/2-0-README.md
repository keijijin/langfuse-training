SDKを使った本格的なトレーシングと、主要フレームワークとの統合を学びます。

## 学習目標

このレベルを修了すると、以下ができるようになります：

- `@observe()` デコレータで関数を自動トレーシングできる
- OpenAIドロップインラッパーでLLM呼び出しを計装できる
- LangChain / LlamaIndex / LiteLLM との統合ができる
- OpenTelemetryベースの計装を構成できる
- Java (Spring Boot) アプリケーションにLangfuseを組み込める
- 実際のアプリケーションにLangfuseを組み込める

## 前提知識

- Level 1 修了済み
- Python、JavaScript/TypeScript、または Java の実務経験
- OpenAI API の基本的な利用経験
