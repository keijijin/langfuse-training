## 学習目標

- Docker Compose / Helm でLangfuseをセルフホストできる
- Web/Worker/データストアのアーキテクチャを理解し、スケーリングできる
- Public REST APIで独自ツールを構築できる
- カスタム評価パイプラインを設計・実装できる
- エンタープライズ要件（SSO、監査、コンプライアンス）に対応できる
